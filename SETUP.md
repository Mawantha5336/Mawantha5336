# Setup

1. On GitHub, create a **public repository named exactly `Mawantha5336`**.
2. Put `README.md` in the repository root.
3. Upload the entire `assets` folder without renaming it.
4. Commit and push. GitHub will automatically show the README on your profile overview.
5. Replace or add project links in the "Selected Systems & Product Work" section when you want to feature specific repositories.
